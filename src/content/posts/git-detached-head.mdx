## The one idea

{/* THE sentence: normally HEAD → branch → commit. In detached HEAD, HEAD → commit
    directly, with no branch in the middle. You can still look around and still
    commit — but there's no branch pointer following you, so new commits have nothing
    holding them once you leave. */}

## The trap: orphaned commits

{/* Intent: the real-world horror story (from the source videos) — dev checks out an old
    commit, fixes a bug, commits, runs `git switch main`, the fix is gone. Because no branch
    ever pointed at it → unreachable → eventually garbage-collected. This is WHY Git warns
    you: not because you broke it, but because it can't hold that commit for you. */}

## Keeping the work
